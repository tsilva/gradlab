# Desktop icons

`icon.png` is an unchanged copy of `image-assets/icon/icon-1024.png`.
`player.png` and `stats.png` are variants edited from it using the built-in imagegen tool.
They are used for native windows, macOS app bundles, and browser favicons.
App-bundle cache keys include each variant’s content hash, so artwork updates need no manual rebuild.

## Player prompt

Edit the supplied GradLab app icon into the PLAYER variant. Preserve the rounded navy square, white outer rim, cyan inner rim, and the recognizable cyan learning curve with white-ring nodes and red goal flag. Add a large, extremely legible circular badge overlapping the lower right interior of the icon, safely within the outer white rim: cyan badge with a bold white right-pointing play triangle. Make the badge about 35 percent of the icon width so its role is obvious at Dock size. Keep the entire icon matching the original polished flat vector-like illustration style and framing. No letters, words, other objects, or background. Transparent outer background, square 1024x1024 PNG. One icon only.
